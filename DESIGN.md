# Design System — 投资雷达

Generated by `/design-consultation` on 2026-03-21. This is the authoritative design source of truth.
All visual and UI decisions should reference this document. Do not deviate without explicit approval.

---

## Product Context

- **What this is:** A personal investment tracking dashboard that follows top investors' SEC 13F filings with AI-generated Chinese analysis.
- **Who it's for:** Single user (personal tool). Chinese-language interface.
- **Space/industry:** Fintech / investment research. Closest peers: Koyfin (professional, institutional), Dataroma (bare data, no design).
- **Project type:** Dashboard web app — Next.js 14 App Router, Vercel-hosted, Neon PostgreSQL.

---

## Aesthetic Direction

- **Direction:** Colorful Fintech / Personal Data Dashboard
- **Decoration level:** Intentional — gradients used deliberately for brand moments (sidebar, AI card, primary gradient). Cards are clean white.
- **Mood:** The data density of a professional tool with the visual warmth of something built for one specific person. Not institutional, not toy-like. Opinionated and personal.
- **Design risks (intentional departures from fintech norms):**
  1. **Gradient sidebar nav** — every fintech peer uses a white sidebar. The purple gradient is the strongest brand signal in the product.
  2. **Per-investor color system** — 5 distinct brand colors for investors, used consistently across chips, sidebar dots, chart lines, and badges.
  3. **AI gradient card** — gradient card treatment reserved exclusively for AI-generated content, making it immediately visually distinct from data.
- **Competitive research:** Koyfin (institutional, dark, corporate), Dataroma (zero design). Both are forgettable. 投资雷达's colorful approach is a deliberate and correct risk in this category.

## Typography

- **Primary / UI:** `Geist` — Vercel's typeface, already wired via `next/font/google` in `layout.tsx`. Clean, neutral, excellent for UI labels, body text, and headings. `--font-geist-sans` CSS variable.
- **Data / Numbers / Tickers:** `Geist Mono` — monospace font for all financial data. Must use `font-variant-numeric: tabular-nums` everywhere numbers appear in columns so they align correctly. `--font-geist-mono` CSS variable.
- **No additional fonts needed.** Geist covers all cases.

### Type Scale

| Name | Size | Weight | Letter-spacing | Usage |
|------|------|--------|---------------|-------|
| Display | 36px / 2.25rem | 800 | −0.8px | Page hero titles |
| Heading | 24px / 1.5rem | 700 | −0.4px | Investor name, page heading |
| Subheading | 16px / 1rem | 600 | 0 | Section title, card header |
| Body | 14px / 0.875rem | 400 | 0 | Main content, descriptions |
| Small | 13px / 0.8125rem | 400 | 0 | Table data, secondary text |

### Typography Rules
- All numbers in data tables and stat cards: `font-family: var(--font-geist-mono)` + `font-variant-numeric: tabular-nums`
- Ticker symbols: `font-family: var(--font-geist-mono)` + `background: #f1f5f9` + `color: #7c3aed` + `padding: 2px 7px` + `border-radius: 6px`
- CIK input fields: `font-family: var(--font-geist-mono)`
- AI-generated text: Geist (not mono) — it's prose, not data

| 2xs | 2px | 0.125rem | `p-0.5` |

### Spacing Rules
- Card internal padding: `20px` (md+)

- **Approach:** Sidebar-fixed + scrollable content area
- **Sidebar:** Fixed, `208px` wide, `100vh` tall, `z-40`. Purple gradient background.
- **Content area:** `margin-left: 208px`, `max-width: 1024px` (max-w-5xl), `padding: 24px`

## Motion

- **Approach:** Minimal-functional — only transitions that aid comprehension or provide touch feedback. No entrance animations. No scroll-driven effects. Data loads instantly or shows a skeleton.

### Timing

| Duration | Value | Usage |
|----------|-------|-------|
| micro | 50ms | Focus ring appearance |
| short | 150ms | **Default for all hover/focus transitions** |
| medium | 250ms | State changes (e.g., sidebar submenu expand) |
| long | 400ms | Not used in this product |

### Easing
- All transitions: `ease-out` (snappy entrance, no bounce)
- `transition: all 150ms ease-out` is the default rule on interactive elements

### Motion Rules
- Hover states on cards/rows: `background-color` change only (no transform)
- Hover on buttons: `opacity: 0.9` + `transform: translateY(-1px)` (subtle lift)
- Nav item active: no transition (instant state change, the user clicked)
- EDGAR preview card: `opacity 0 → 1` + `transform: translateY(-4px) → 0` at `150ms ease-out` (fade-in from slightly above)
- Inline confirmation reveal: no animation (instant, keeps user's attention on the action)
- AI shimmer: `opacity` pulse at 1.5s cycle (generating state)

## Accessibility

- **Contrast:** All text must meet WCAG AA (4.5:1 for normal text, 3:1 for large text). White-on-gradient passes for the sizes used.
- **Touch targets:** 44×44px minimum. Use `p-3` padding minimum on interactive elements.
- **Focus rings:** `box-shadow: 0 0 0 3px rgba(124,58,237,0.1)` on all focusable elements.
- **Screen readers:** Delete buttons use `aria-label="删除 {name_cn}"`. Progress bar uses `role="progressbar"`. CIK input uses `<label>` (visually hidden with `sr-only` if not shown).
- **Color-only information:** Change type is always communicated via both color AND a text label/icon (↑, ↓, 新建, 清仓) — never color alone.

## Mobile / Responsive (iPhone 16 Pro Max — 430px viewport, Safari)

Mobile is a **required** target. The user checks the site on iPhone 16 Pro Max via Safari.

### Breakpoint
Single breakpoint: `md` (768px). Below = mobile, above = desktop.
All new components are written **mobile-first** — base styles for mobile, `md:` overrides for desktop.

### Layout Changes at `< 768px`
| Element | Desktop | Mobile |
|---------|---------|--------|
| Sidebar | Fixed 208px, always visible | Hidden (`hidden md:flex`) |
| Top nav | None | Fixed 56px bar: Logo + hamburger button, purple gradient |
| Hamburger menu | — | Overlay drawer matching desktop sidebar content |
| Content margin | `ml-52` | `ml-0` |
| Content padding | `px-6 py-6` | `px-4 py-4` |
| Max width | `max-w-5xl` | `max-w-full` |

### Grid Behavior
| Desktop | Mobile |
|---------|--------|
| 4-column stat cards | 2-column (`grid-cols-2`) |
| 2-column card grids | 1-column (`grid-cols-1`) |
| 3-column grids | 1-column |

### Tables
- Container: `overflow-x: auto` — horizontal scroll, never wrap columns
- Hidden columns on mobile (use `hidden md:table-cell`): shares count, CIK, secondary data
- Always visible: ticker, change type badge, value
- Row tap target: `py-3.5` minimum

### Charts (Recharts)
- Wrapper: `overflow-x: auto`
- Chart fixed inner width: `480px` (allows horizontal scroll on mobile)
- Y-axis width: `44px` on mobile (vs `60px` desktop)

### Touch Targets
- All interactive elements: minimum `44×44px` (`min-h-[44px]` + adequate padding)
- Table rows: `py-3.5` minimum
- Nav items in drawer: `py-3` minimum

### Type Scale (mobile overrides)
| Role | Desktop | Mobile |
|------|---------|--------|
| Display | 36px | 24px |
| Heading | 24px | 20px |
| Stat card value | 26px | 20px |
| Body | 14px | 14px (unchanged) |
| Label | 11px | 11px (unchanged) |

## Dark Mode

Dark mode is not in scope for v1.1. If added in future:
- Background: `#0f172a` (slate-900)
- Card: `#1e293b` (slate-800)
- Border: `#334155` (slate-700)
- Text: `#f1f5f9`
- Gradients: reduce saturation 10–15% on sidebar and button gradients
- AI card: same gradient, slightly reduced shadow
